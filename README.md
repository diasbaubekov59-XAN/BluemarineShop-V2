# BluemarineShop - Интернет-магазин одежды Казахстана

Современный, полнофункциональный интернет-магазин одежды с каталогом товаров, корзиной и фильтрацией.

## 🎯 Особенности

### Основной функционал
- ✅ **Каталог товаров** - 12 товаров различных категорий (женская и мужская одежда)
- ✅ **Корзина** - полнофункциональная система с сохранением в localStorage
- ✅ **Фильтрация** - по категориям (Женское/Мужское)
- ✅ **Поиск** - поиск товаров по названию в реальном времени
- ✅ **Сортировка** - сортировка по цене, популярности, новизне
- ✅ **Фильтр по цене** - ползунок для выбора диапазона цен
- ✅ **Избранные товары** - сохранение в localStorage
- ✅ **Быстрый просмотр** - модальное окно товара с подробной информацией
- ✅ **Слайдер** - автоматический слайдер в hero секции
- ✅ **Оформление заказа** - форма с вводом данных и выбором способа оплаты

### Дополнительные страницы
- 📄 **О нас** (about.html) - информация о компании, история, преимущества
- 🚚 **Доставка и оплата** (delivery.html) - условия доставки и методы оплаты
- 📞 **Контакты** (contacts.html) - контактная информация и форма связи
- 🔗 **Footer** - навигационные ссылки, контакты, социальные сети

## 🛠️ Технологии

- **HTML5** - разметка
- **CSS3** - стилизация (flexbox, grid, медиазапросы)
- **Vanilla JavaScript** - функционал без библиотек
- **localStorage** - сохранение данных в браузере
- **Font Awesome 6** - иконки
- **Google Fonts** - типография

## 🚀 Начало работы

1. Откройте `index.html` в браузере
2. Выберите категорию товара или используйте поиск
3. Кликните на товар для быстрого просмотра
4. Добавьте товар в корзину
5. Нажмите на корзину для оформления заказа
